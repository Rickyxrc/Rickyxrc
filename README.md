# Ricky

电子科技大学本科在读。主要使用 C++、Python、Rust，日常在 Linux 下开发，使用 Git/GitHub 管理项目。对 CLI 工具、自动化、Linux 基础设施和系统工具感兴趣。

## 技能
- 语言：C++、Python、Rust，能使用常见标准库和第三方库完成工具开发。
- 系统与工具：Linux（Ubuntu、Arch、NixOS 等）、Nix、Git、CLI、服务器运维。

## 项目
- [cf-tool (fork)](https://github.com/Rickyxrc/cf-tool)：Codeforces CLI 提交工具；添加 Nix 构建支持，使其可在 NixOS 上运行。
- [at-cli](https://github.com/Rickyxrc/at-cli)：从零实现的 AtCoder CLI 提交工具；因 AtCoder 限制脚本提交而归档。
- [MCDRpost (fork)](https://github.com/Rickyxrc/MCDRpost)：Minecraft MCDR 传送物品插件；适配高版本 `/data` 命令数据格式，并改进命令输出。
